# Grade 9 Python Practical Import

The accompanying DOCX is formatted for the portal's practical-question importer.

- 5 practical questions
- 8 variants under each question
- 10 marks per question
- Total: 50 marks
- 8 students can be assigned one unique variant per question when their roster order is 1–8
- Language is detected as Python
- Each question is imported as one practical question with 8 variants
- The portal's practical parser has been updated to recognize multiple `QUESTION` sections with independent variant pools.

For 8 students, the deterministic assignment is:

- Student 1 → Variant 1 of Questions 1–5
- Student 2 → Variant 2 of Questions 1–5
- …
- Student 8 → Variant 8 of Questions 1–5

If there are more than 8 students, variants repeat round-robin according to roster order.
